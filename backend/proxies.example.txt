# 外部代理列表示例 (购买的代理 IP)
# 格式: 协议://[用户名:密码@]主机:端口
# 或者是: 协议://主机:端口
# 支持 http, https, socks5 协议
# 每行一个，支持使用 # 开头的注释

# 示例 1: 带账号密码的 HTTP 代理
# http://user123:pass456@112.113.114.115:8888

# 示例 2: 无账号密码的 SOCKS5 代理
# socks5://122.123.124.125:1080

# 示例 3: HTTPS 代理
# https://myproxy.com:443

# 通用四段格式
203.0.113.10:8080:PROXY_USER:PROXY_PASSWORD
203.0.113.11:1080:PROXY_USER:PROXY_PASSWORD
